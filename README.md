# CodeAlpha EDA Series 📊

## Exploratory Data Analysis

This project is part of my Data Science internship at CodeAlpha.  
The main purpose of this project is to explore and understand a sales dataset using Python and data visualization techniques.

## Dataset

The dataset contains sales information with 9,800 records and 18 columns.

Some important columns are:

- Order Date
- Ship Mode
- Customer Name
- Segment
- Region
- Category
- Sub-Category
- Product Name
- Sales

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
- Jupyter Notebook

## Analysis Performed

The following analysis was performed:

1. Loaded and explored the dataset.
2. Checked the dataset structure and data types.
3. Checked missing values.
4. Generated descriptive statistics.
5. Analyzed the distribution of Sales.
6. Compared total Sales by Category.
7. Compared total Sales by Region.
8. Analyzed Sales by Segment.
9. Identified the Top 10 Products by Sales.

## Key Insights

- Technology has the highest total sales among the three categories.
- The West region has the highest total sales.
- The South region has the lowest total sales among the four regions.
- The Consumer segment contributes the highest sales.
- A small number of products contribute significantly to total sales.
- Sales values are highly skewed, with a few products having very high sales.
